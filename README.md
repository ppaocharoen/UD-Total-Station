## ใช้กับ SAP2000

1. `python tools/sap_export.py โครงการ.bm.json` ได้ `โครงการ.s2k` และ `โครงการ.sap.json` (จำรุ่นโมเดลที่ส่งไป)
2. SAP: File > Import > SAP2000 .s2k Text File > New model แล้วรัน
3. SAP: File > Export > SAP2000 MS Excel Spreadsheet เลือก Analysis Results: Joint Output > Reactions, Displacements และ Element Output > Frame Output > Element Forces - Frames บันทึกชื่อเดียวกับ `.s2k` (เช่น `โครงการ.xlsx`)
4. `python tools/sap_results.py โครงการ.bm.json โครงการ.xlsx --write`

**SAP2000 รันวิเคราะห์ไม่ได้ถ้า path ของไฟล์ .sdb มีภาษาไทย** — import แล้ว Save As ไปโฟลเดอร์/ชื่อภาษาอังกฤษก่อนกด Run (ท12 ทดสอบที่ `_sap_test\t12.sdb` 22 พ.ย. 2569: ΣFz SDL 25,795.1 · LR 5,200 ตรงกับที่ loadgen ใส่ · DL 23,262.9 = น้ำหนักตัวเองจาก SAP)

น้ำหนักบรรทุก: `python tools/loadgen.py โครงการ.bm.json --write` (DL = น้ำหนักตัวเองจาก SAP อย่างเดียว · SDL แผ่นมุง/ฝ้า/ผนัง · LR) — หน่วยน้ำหนักจาก `_claude_kb/น้ำหนักวัสดุ.json` ถ้ามี ไม่งั้น `tools/unit_weights.json`

ตัวส่งออกแปลงโมเดลตำแหน่งจริงเป็นโมเดลวิเคราะห์ให้เอง (ไม่แก้ .bm.json):
- ไม่ส่งเสาเอ็น/ทับหลัง (น้ำหนักคิดรวมในผนัง)
- ปลายชิ้นที่วางชน/วางบนชิ้นอื่น (หัวเสาใต้อะเส ดั้งบนอะเส จันทันบนอะเส/คอร์ดบน อะเสชนข้างอะเส) → จุดบนแนวแกนชิ้นที่รองรับ + Body constraint (ข้อต่อแข็ง)
- แปที่วางบนหลังจันทัน → ลดลงมาที่แนวแกนจันทันและต่อที่จุดตัดทุกตัว
- ท่อเหล็กกล่อง → Box/Tube · 2C ประกบคู่ (กล่องปิด) → General ค่าหน้าตัดจาก `double_c_props` · ทั้งสองใช้วัสดุเหล็ก `<วัสดุ>-ST`
- เตือนกลุ่มชิ้นส่วนที่ไม่ต่อถึงฐานราก
ถ้าแก้โมเดลหลังส่งออก ผลที่อ่านกลับจะถูกนับว่าเก่า (stale) จนกว่าจะส่งออกและวิเคราะห์ใหม่

## หลักของไฟล์ `.bm.json`

- หน่วย ม. / กก. (kgf) / ksc; พิกัดเป็นตัวเลขเมตร X ตามกริดตัวเลข Y ตามกริดตัวอักษร Z ขึ้น
- ชิ้นส่วนมี `id` ไม่ซ้ำ และ `mark` = ชื่อตามแบบ
- ทุกชิ้นมี `status` (from_drawing, from_survey, user, assumed, computed, missing) ค่าที่ต่างจากสถานะรวมใส่ใน `field_status`
- f'c ห้ามเป็น assumed; SD40 / SR24 / site class D สมมติได้ (ติดป้าย)
- เหล็กเสริมอยู่ใน `design` เสมอ แม้มาจากแบบ
- `results`, `design`, `quantities` เก็บ `model_hash` ตอนสร้าง ถ้าโมเดลเปลี่ยนจะถูกนับว่าเก่า (stale)

- คลังราคาสืบกลาง (tools/survey_lib.gs + tools/survey_lib.appsscript.json): ทุกคำสั่งต้องมีรหัสทีม ส่งแบบ POST · ล็อกชั่วคราวเมื่อใส่รหัสผิดซ้ำหลายครั้ง · ภาพในโฟลเดอร์ Drive เป็นส่วนตัว (ดึงผ่านสคริปต์) · สิทธิ์ `spreadsheets` + `drive.file` เท่านั้น · ข้อความขึ้นต้น = + - @ ถูกเก็บเป็นข้อความ · ลบ = ย้ายไปชีต `deleted`
- หน้าเว็บ: ภาพหลักฐานรับเฉพาะ data URL ของ JPEG/PNG/WebP · `?pricing=` รับเฉพาะ `ppaocharoen.github.io/UDmaterial-price/` หรือ localhost · three.js มี SRI · รหัสทีมเก็บเฉพาะแท็บนี้ เว้นแต่ติ๊ก "จำรหัส"
- ห้ามใส่รหัสทีมลงใน repo (repo เป็นสาธารณะ) — ตั้งใน Script properties เท่านั้น
